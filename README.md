# Newsletters

## JMums

[Télécharger la newsletter complète (.zip)](https://github.com/yossefmechaly-sys/Newsletters/raw/refs/heads/main/jmums/newsletter-jmums.zip)

1. Téléchargez et décompressez le ZIP.
2. Ouvrez `newsletter.html` pour voir le résultat sur votre ordinateur.
3. Pour l’envoi, importez **`newsletter-envoi.html`** dans votre outil de newsletter. Les images sont déjà reliées à leurs URL HTTPS dans ce dépôt.

Le dossier [jmums](jmums/) contient également :

- [Le HTML pour l’envoi](jmums/newsletter-envoi.html).
- [Le HTML avec des images locales](jmums/newsletter.html) et le dossier [images](jmums/images/).
- [Un aperçu autonome](jmums/apercu-newsletter.html), à télécharger puis ouvrir dans un navigateur.
- [La version email avec images intégrées (.eml)](https://github.com/yossefmechaly-sys/Newsletters/raw/refs/heads/main/jmums/newsletter-jmums.eml), pour un logiciel de messagerie compatible.
- [La notice d’utilisation](jmums/LISEZ-MOI.txt).

Le visuel d’origine est conservé. Sur mobile, l’affiche s’adapte à l’écran et les liens du bas s’affichent sur trois lignes, chacun centré avec son icône. L’affiche et le lien du site ouvrent JMums ; les liens Facebook et Instagram ouvrent les pages demandées.

Les badges App Store et Google Play sont cliquables et ouvrent les fiches de l’application. Les liens du bas sont centrés et rapprochés sur mobile.

Le QR code est également cliquable vers https://onelink.to/ndzn4z. Son contenu a été décodé et pointe déjà vers cette même adresse lors du scan.
